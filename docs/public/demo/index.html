How it's built — one function

import { webmcp } from 'simple-webmcp';
const addToCartTool = webmcp(addToCart, {
  description: 'Add product to cart'
});
// still callable:
await addToCartTool({productId:'p1', quantity:1});
// vanilla: await tool.register()
// React: const tool = useWebMCP(addToCart, {description})
// useTool alias also: useTool(addToCart, {...})
Without: manual registerTool({name,inputSchema,execute}) + AbortSignal.
Same function. One line.
Show raw registerTool vs webmcp 
// raw
document.modelContext.registerTool({
  name: 'add_to_cart',
  description: 'Add…',
  inputSchema: {type:'object', properties:{productId:{type:'string'}, quantity:{type:'number'}}, required:['productId','quantity']},
  execute: ({productId,quantity})=>addToCart({productId,quantity})
}, {signal})
// with simple-webmcp
webmcp(addToCart, {description:'Add…'}) // inferred inputSchema + fields patch
